# Order service using Lambda and Serverless Framework

## Installation

* Clone the repository

    git clone https://github.com/G-Network/order-service/tree/develop
    
* Set up env variable `GITHUB_AUTH_TOKEN` with your GitHub token. (Settings -> Developer Settings -> Personal access tokens)

* Install node dependencies

    npm i

* Start the application

    npm start (sls offline mode)
        
    npm run debug (sls offline in debug mode)
